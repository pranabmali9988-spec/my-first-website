# Mali Krishi Farm Website

A responsive starter website for Mali Krishi Farm, built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors and responsive styling
- `script.js` — mobile navigation and dynamic footer year

## Preview
Open `index.html` in a browser, or enable GitHub Pages in the repository settings to publish it.

## Before publishing
1. Replace the sample email address in `index.html` with the farm's real email.
2. Update the farm introduction and product list with accurate details.
3. Add the farm's real location, phone number and social links.
4. Replace the sample stock photos with photos you own or have permission to use.

The current website uses sample copy and illustrative stock imagery; it does not claim specific certifications or farming practices.
